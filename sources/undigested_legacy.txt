# The undigested legacy tail: sources cited before the digest discipline, listed exactly.
#
# A source with no `content_sha256` cannot be re-fetched, so `check_refetch` - the only gate
# that goes and looks - is blind to it. `check_verification` requires a digest on any source
# backing a CLAIMED DATE, which is the right scope for a gate clearable inside one PR, and it
# leaves this behind.
#
# An explicit list rather than a count, because a count only prevents NET growth: a pass could
# digest an old source while citing a new undigested one and the number would not move. Every
# entry here is grandfathered; anything NOT here must carry a digest.
#
# Shrinking it is the point. When a refresh pass digests a source, delete its line - and
# `tests/test_digest_ratchet.py` fails if a line here no longer describes an undigested source,
# so the list cannot rot into a permanent exemption.
#
