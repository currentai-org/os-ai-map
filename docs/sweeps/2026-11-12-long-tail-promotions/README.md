# Long-tail promotions: 2026-11-12

A promotion pass over the registry tail in published categories. Rows were ranked by the GitHub
stars and trailing-month package or Hugging Face downloads their artifacts showed on 2026-11-12,
and the highest-signal rows across categories were researched into head products through
`add-product`. Rows in preliminary categories were left for `promote-category`.

Each product's evidence is cited in its score file, and the registry row it came from was removed
in the same change. A row researched and not promoted stays in the tail; the pull request lists it
with the reason. This directory holds only what has no other home: the country ledger for
organizations created during the pass (`countries/`), which `tests/test_org_country.py` reads.
